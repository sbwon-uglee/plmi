# 플밍이

맥 화면 가장자리로 가끔 놀러 오는 작은 젤리예요. 들어와서 잠깐 놀다가 다시 나갑니다.

소개 페이지: https://sbwon-uglee.github.io/plmi/

## 설치

터미널에 한 줄을 붙여 넣고 Return 을 누르면 응용 프로그램 폴더에 넣고 바로 띄웁니다.

```bash
curl -fsSL https://github.com/sbwon-uglee/plmi/releases/latest/download/install.sh | sh
```

| 필요한 것 | |
|---|---|
| macOS | 13.3 이상 |
| 맥 | Apple Silicon, Intel 모두 |
| 권한 | 없음 |

## 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| 지금 부르기 | 어느 앱에서든 ⌃⌥P. 와 있을 때 한 번 더 누르면 돌려보내요 |
| 잠깐 쉬게 하기 | 메뉴 막대의 플밍이 아이콘에서 30분, 1시간, 계속 쉬기 |
| 크기, 빈도, 오는 종류 바꾸기 | 메뉴 막대 아이콘에서 설정 |
| 놀아 주기 | 와 있을 때 커서로 문지르면 웃고, 커서를 3초 올려 두면 튕겨 떠올라요 |

## 새 버전

앱이 하루에 한 번 이 저장소의 최신 릴리스를 확인해요. 새 버전이 있으면 메뉴 막대 아이콘에 빨간 점이 찍히고, 설치를 누르면
받아서 바꿔 끼운 뒤 다시 띄웁니다. 받은 파일은 앱 안에 든 공개키로 서명을 확인한 다음에만 씁니다.

## 지우기

1. 메뉴 막대의 플밍이 아이콘에서 플밍이 종료를 누릅니다.
2. 응용 프로그램 폴더의 플밍이를 휴지통으로 옮깁니다.
3. 설정과 기록까지 지우려면 `~/.config/desktop-char` 폴더와 `~/Library/Logs/플밍이` 폴더를 지웁니다.

## 브라우저로 zip 을 받았다면

이 앱은 Apple 의 공증을 받지 않았어요. 브라우저로 받은 앱을 처음 열면 macOS 가 막는데, 시스템 설정의 개인정보 보호 및
보안에서 "그래도 열기"를 한 번 누르면 됩니다. 위의 설치 명령으로 설치하면 이 과정이 없어요.
